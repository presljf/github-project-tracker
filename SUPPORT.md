# Support

Project Tracker OS is supported on a **best-effort, no-SLA** basis.

## Docs

- [Playbook](./docs/GITHUB_PROJECT_TRACKER_PLAYBOOK.md) — conceptual/operating model
- [Downstream feedback](./docs/DOWNSTREAM_FEEDBACK.md) — reporting, triage, versioning, contributions

The exhaustive HOW TO USE suite, reference, troubleshooting, adoption/upgrading guides, style guide, and printable cards are available now.

## Report a bug or request a feature

- [Downstream bug report](https://github.com/presljf/github-project-tracker/issues/new?template=downstream-bug.yml)
- [Downstream feature request](https://github.com/presljf/github-project-tracker/issues/new?template=downstream-feature.yml)
- [All issue forms](https://github.com/presljf/github-project-tracker/issues/new/choose)

Include your originating project, pinned tracker version, environment, reproduction/context, expected vs actual, impact, and workaround.

## Security

Do **not** open a public issue for vulnerabilities. Follow [SECURITY.md](./SECURITY.md).

## Contributions

Small, well-scoped PRs are welcome; discuss larger changes in an issue first. PRs must pass CI and include docs updates when behavior changes.
