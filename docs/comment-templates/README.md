# Lifecycle comment templates

Copy the relevant template when operating a tracker issue. These are also embedded in the playbook.

| Template | Use |
|---|---|
| `check-in.md` | task start (owner/executor/branch/DoR/evidence) |
| `update.md` | meaningful during-work update |
| `check-out.md` | task completion/evidence |
| `blocker.md` | blocked state |
| `plan-change.md` | scope/estimate/acceptance change |
| `sprint-close.md` | sprint exit/demo |
| `release-close.md` | release gates/artifacts/close |

Rules:
- One check-in and one check-out per task.
- Record the owner and `Executor:` explicitly.
- Attach evidence links, not just claims.
- Plan changes are dated and reflected in the sprint/release trackers and Project fields.
