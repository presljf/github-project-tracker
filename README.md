# github-project-tracker

Portable GitHub project-tracker operating system: playbook, config schema/templates, generic Node profile, reusable Actions, release profiles, exhaustive HOW TO USE docs, and downstream feedback intake.

## Start here

- [Playbook](docs/GITHUB_PROJECT_TRACKER_PLAYBOOK.md) — setup, lifecycle, statuses/WIP, check-in/out, audit, Actions, porting
- [Support](SUPPORT.md) — docs, reporting, contributions
- [Downstream feedback](docs/DOWNSTREAM_FEEDBACK.md) — report bugs/features upstream, versioning/no-fork policy
- [Security](SECURITY.md) — private vulnerability reporting; never public issues
- [Issue forms](https://github.com/presljf/github-project-tracker/issues/new/choose)

## Status

Project Tracker OS v1.0.0 is in active development. The template stays private through its own v1.0.0 validation; downstream adoption starts after release.
